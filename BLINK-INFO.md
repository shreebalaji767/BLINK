# BLINK — NPC Social

BLINK is a browser-only fictional-character social feed and multiverse NPC simulation.

## How it works

- Static HTML, CSS, and ordinary JavaScript served through GitHub Pages.
- NPC posts, comments, reactions, and simulated friend requests are generated locally in the visitor browser.
- Visitors can browse NPC profiles, search and filter the directory, write Observer posts, comment, react, follow, save posts, and manage simulated friend requests.
- Local social state is stored in browser localStorage; clearing site storage can remove it.
- NPC activity is fictional. There are no real user-to-user messages, real NPC accounts, server-side social graph, or cross-device synchronization.

## Privacy and limitations

The current GitHub Pages application does not use the account-authentication or temporary-media system described in earlier project notes. The deployed NPC Social experience does not require sign-up, email, password, a backend, a database, or an external API.
Posts and interactions are local to one browser session. Friend requests are generated by the app JavaScript and do not contact another person. Do not treat simulated profiles or activity as real accounts.

## Run locally

Open index.html in a modern browser. No package installation or build step is required.

## Main files

- index.html — static application shell and navigation
- styles.css — responsive styling
- app-social-requests.js — active NPC social application
- app.js — retained legacy script; not loaded by the active page
- .github/workflows/ci.yml — syntax and static smoke validation
- .github/workflows/pages.yml — GitHub Pages deployment
